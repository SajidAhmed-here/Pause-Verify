
**Pause & Verify** is a privacy-first Chrome extension designed to help you navigate Facebook more mindfully. By adding an automated verification check right when you hit the "Share" button, it empowers you to spot potentially AI-generated content and misleading captions before spreading them further.

Built with local machine learning and natural language processing (NLP) models, this extension processes everything directly on your device, ensuring zero data leaves your browser.

## 🚀 Install Pause & Verify

**Now available on the Chrome Web Store!**

## 🚀 Features

### Core Detection

- **AI Media Estimation:** Analyzes images and samples multiple frames of videos to provide a probability score of the content being AI-generated.
- **Label Spotting:** Automatically detects and highlights Facebook's native "AI info" labels that might otherwise be easily missed.
- **Share-Bait Flagging:** Utilizes NLP models to spot manipulative, engagement-baiting captions (e.g., "everyone needs to see this!").

### Digital Wellbeing (Optional)

Take control of your browsing experience with built-in focus tools:

- **Grayscale Mode:** Remove the psychological hook of bright colors from your feed.
- **Stop Autoplay:** Prevent videos from automatically playing as you scroll.
- **Pause Stories:** Stop Facebook Stories from auto-advancing, letting you view content at your own pace.
- **Screen-Time Limit:** Set active browsing limits to receive notifications when it is time to log off.

### 🔒 100% Private

- **Local Processing:** All models and scripts are bundled locally within the extension package.
- **No Cloud Uploads:** Your feed, images, and data are never uploaded to an external server.
- **No Hassle:** Requires no API keys, no account creation, and no sign-ups.

## ⚠️ Important Note on AI Detection

**AI detection is never 100% accurate.** Pause & Verify provides an *estimate* to help you think twice—it is not a definitive final verdict. Occasionally, real videos and photos may be flagged (false positives), and the newest AI generation tools can sometimes slip through undetected (false negatives). Always use your best judgment and context clues alongside this tool.

## 🛠️ Installation (Manual)

1. Download or clone this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extension directory.
5. The extension is now active on all `facebook.com` URLs.

*Alternatively, install it directly from the [Chrome Web Store](https://chromewebstore.google.com/detail/ncmcaddagpnhhognjnmflbkhdepoenmk).*
